# Mujahid Abbas Portfolio

Official portfolio of Mujahid Abbas, Expert AI Web & Mobile App Developer. Built with HTML5, CSS3, and modern JavaScript. Showcases custom Laravel SaaS, Flutter cross-platform mobile apps, n8n/Zapier automations, and high-performance digital solutions for clients in the US, UK, and Gulf.

## Pages
- index, about, services, projects, markets, blog (+2 posts), hire-me, contact, 404
- All links are relative so the site works when opened directly and on Netlify.

## Edit
- Open `tools/build.py`, fill `SOCIALS`, `LIVE`, and `EMAIL`, then run: `python tools/build.py`
- Styling: `assets/css/style.css`
- Behaviour: `assets/js/site.js`
- Images: `images/projects` and `images/myimage`

## Deploy
- Drag this folder to Netlify.
- Submit `sitemap.xml` in Google Search Console and Bing Webmaster Tools.
